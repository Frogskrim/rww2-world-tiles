# RWW2 world map tiles

Image tiles of the world map in RWW2 Interactive: the land itself with nobody on it, in the Miller projection, 1,024 px square. Each file is named `L<level>_<column>_<row>.jpg`, where the level is the width of the whole world in pixels: 2,048, 4,096 and 8,192 cover the whole world, 16,384 covers all land, and 32,768 and 65,536 cover Europe, the Eastern Front to the Urals, North Africa and the Middle East.
